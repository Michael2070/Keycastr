# Keycastr（快捷键提示）

一个面向 Windows 的键盘快捷键视觉反馈工具。当你按下已登记的快捷键时，它会在屏幕上弹出提示气泡，直观地确认你的每一次操作——特别适合直播、录屏、演示、教学等需要“让观众看见按键”的场景。

> 当前版本：**1.4.0-beta**（更名自“快捷键提示”，设置界面中仍以括号标注）

## 功能特性

- **快捷键视觉反馈**：按下组合键后屏幕立即显示提示气泡，支持重复次数（`Ctrl+S ×3`）、自动淡出、拖动定位。
- **我的快捷键**：手动录制任意按键组合，优先级最高。
- **软件预设库**：内置 26 套常用软件快捷键预设，支持搜索、逐个启用/停用、**修改预设中的快捷键（录制替换）**、修改提示文字、一键全部启用/禁用/恢复默认。
- **自动模式**：检测当前前台窗口，自动启用对应软件的快捷键预设；需手动开启并同意隐私声明，且不跨会话记忆。
- **持续输出模式**：按下 `Ctrl/Shift/Alt/Win` 立即显示，并实时追加后续按键与点击次数，适合需要看清自己键位操作的用户。
- **外观自定义**：窗口透明度与**文字透明度独立调节**、显示时长、淡出时长、位置（预设位置或按住拖拽自定义）、背景/文字/边框颜色、字号、固定宽高；进入外观页即显示**真实提示框实时预览**，修改即时生效；兼容不同 DPI 缩放、分辨率切换与多显示器。
- **系统集成**：开机自启（注册表 + 启动文件夹双保险）、单实例保护、系统托盘菜单（测试 / 设置 / 重启程序 / 模式开关 / 退出）。
- **未保存修改提醒**：在设置中做出修改后点取消或关闭窗口，会提示“保存并退出 / 退出 / 取消”。

## 快速开始

### 直接使用

下载发行版 [Keycastr-1.4.0-beta.exe](dist/Keycastr-1.4.0-beta.exe)（绿色单文件，无需安装 Python，双击即可运行）。设置保存在 `%APPDATA%\ShortcutNotifier\shortcut_settings.json`，升级或移动 exe 不丢失设置。

### 从源码运行

环境要求：Windows 10/11，Python 3.10+（开发环境使用 3.13）。

```bash
pip install customtkinter keyboard pystray pillow
python shortcut_notifier.py
```

### 打包 exe

```bash
pip install pyinstaller
build_exe.bat
```

打包产物输出到 `dist\Keycastr-x.x.x-beta.exe`，可分享给没有 Python 环境的用户。

## 使用说明

程序启动后驻留系统托盘，右键托盘图标可打开菜单：

- **测试提示**：显示固定测试气泡，确认提示功能正常。
- **设置**：打开设置窗口（我的快捷键 / 软件预设 / 外观 / 系统）。
- **重启程序**：重启软件，用于恢复异常状态。
- **自动模式 / 持续输出模式 / 开机自启**：快速开关，勾选状态实时刷新。
- **退出**：退出程序。

### 设置页说明

- **我的快捷键**：录制并管理自定义快捷键。
- **软件预设**：搜索并管理各软件预设；顶部为自动模式开关。
- **外观**：调整气泡样式与位置；进入本页后屏幕会持续显示真实提示框作为实时预览，可点击“拖动定位”直接把提示框拖到目标位置。
- **系统**：开机自启、自动模式与任务管理器说明、设置文件路径（可复制 / 跳转）、关于信息（软件名 / 开发者 / 开发环境 / AI 模型 / 平台）。

设置页的修改需要点击“保存”后生效；若未保存就点击取消或关闭窗口，会询问是否保存。

> 提示：调出任务管理器（尤其是以管理员权限运行时）可能导致按键提示暂时失效；关闭任务管理器后通常会自动恢复，如仍异常可重启程序。

## 自定义与开发

快捷键预设数据集中在 `preset_library.py`，格式如下：

```python
PRESET_LIBRARY = {
    'vscode': {
        'name': 'Visual Studio Code',
        'category': '开发',
        'description': 'VS Code 常用快捷键',
        'apps': ['code.exe'],            # 前台程序名，支持 * 通配
        'title_keywords': [],            # 窗口标题关键词（可选）
        'shortcuts': {
            'ctrl+shift+p': {'display': 'Ctrl+Shift+P 命令面板'},
            'f5': {'display': 'F5 开始调试'},
        },
    },
}
```

添加新软件时，在 `PRESET_LIBRARY` 中新增条目，并把 id 加入 `PRESET_ORDER` 列表即可；按键名必须是 keyboard 库可识别的键名（如 `ctrl+shift+p`、`page up`、`f5`）。

## 常见问题

### 调出任务管理器后提示失效

Windows 对低权限进程的键盘钩子有限制，调出任务管理器（尤其是以管理员权限运行时）可能导致按键提示暂时失效。程序内置自动恢复机制（真实按键状态校准 + 轮询兜底），关闭任务管理器后通常会在 1 秒内自动恢复；如仍异常，可通过托盘菜单“重启程序”解决。

### 开机自启不生效

程序默认开启开机自启，首次运行会自动写入注册表与启动文件夹。若被安全软件拦截，可在“系统”页关闭后重新开启。

### 管理员权限窗口无法显示按键提示

当当前窗口以管理员权限运行时，出于系统安全限制（UIPI），低权限进程无法监听其按键输入；这是 Windows 的系统行为，非本程序缺陷。
